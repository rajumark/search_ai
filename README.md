## ✨ What is Photo Search AI?

**Photo Search AI** is a revolutionary Android application that transforms how you find photos on your device. Instead of endlessly scrolling through thousands of images, simply **type what you're looking for** and let our advanced AI find it for you!

Ever needed to find:
- 📸 That **receipt** from last month's purchase?
- 🎫 A **ticket** screenshot with specific booking details?
- 📝 An image containing a **phone number** or **address**?
- 🛒 A **product barcode** you photographed?
- 🌅 Photos with **sunsets**, **mountains**, or **dogs**?

**Photo Search AI makes it effortless!** Our intelligent processing extracts text, recognizes objects, and detects barcodes from all your photos — enabling lightning-fast searches that feel like magic.

2. Enable "Install from unknown sources" if prompted
3. Install the APK on your Android device
4. Grant media permissions when requested
5. Let the app process your photos (happens in background!)
6. Start searching! 🎉

### Option 2: Build from Source

```bash
# Clone the repository
git clone https://github.com/rajumark/search_ai.git

# Navigate to project directory
cd search_ai

# Build the debug APK
./gradlew assembleDebug

# Or build the release APK
./gradlew assembleRelease
```

**Requirements:**
- Android Studio Hedgehog or later
- JDK 17
- Android SDK 35
- Gradle 8.x

## 🚀 Getting Started

1. **Launch the App** — Open Photo Search AI on your device
2. **Grant Permissions** — Allow access to your photos when prompted
3. **Automatic Processing** — The app begins analyzing your photos in the background
4. **Start Searching** — Use the search bar to find any image instantly!

### 💡 Pro Tips

- **Long phrases work great!** Try searching for "confirmation email" or "receipt total"
- **Object search** — Search for "dog", "sunset", "food" to find photos by content
- **Barcode search** — Search for product codes or QR content
- **Partial matches** — Even partial text matches will surface relevant photos

## 📐 Architecture

Photo Search AI follows **Clean Architecture** principles with the **MVVM** pattern:

```
📁 com.photo.searchai
├── 📂 data
│   ├── 📂 datastore       # DataStore preferences
│   └── 📂 local           # Room database, DAOs, Entities
├── 📂 datasource          # Data source implementations
├── 📂 di                  # Hilt dependency injection modules
├── 📂 navigation          # Navigation routes and graphs
├── 📂 ocr                 # ML Kit processors (OCR, Barcode, Labels)
├── 📂 repository          # Repository implementations
├── 📂 service             # Foreground services
├── 📂 ui
│   ├── 📂 home            # Home screen with gallery
│   ├── 📂 search          # Search functionality
│   ├── 📂 fullscreen      # Full-screen image viewer
│   ├── 📂 history         # Processing history
│   └── 📂 theme           # Material 3 theming
├── 📂 worker              # WorkManager background tasks
└── 📂 battery             # Battery optimization handling
```

## 🔐 Privacy & Security

Your privacy is our top priority:

| Aspect | Our Commitment |
|--------|----------------|
| **📍 On-Device Processing** | All AI/ML processing happens locally on your device |
| **🚫 No Cloud Upload** | Your photos are never uploaded to any server |
| **🔒 No Data Collection** | We don't collect, store, or share any personal data |
| **🔌 Fully Offline** | Works completely offline after initial download |
| **📱 Local Storage Only** | All extracted data is stored only in your device's local database |
